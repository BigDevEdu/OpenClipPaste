# TRD — ClipPaste (MVP)

> Technical Requirements Document · v1.1 · 2026-09-29 · Complementa o [PRD](PRD.md)

## 1. Decisões

| Item | Escolha |
|---|---|
| Uso | Pessoal. Build local, assinatura ad-hoc, sem sandbox, sem notarização |
| Linguagem / UI | Swift 6, SwiftUI dentro de `NSPanel` (AppKit) |
| Build | Swift Package Manager (só Command Line Tools, **sem Xcode**) + `scripts/bundle.sh` |
| Dependências | **Nenhuma** (AppKit, Carbon, Foundation, CryptoKit) |
| Persistência | `index.json` + `blobs/*.png` em `~/Library/Application Support/ClipPaste/` |
| Alvo mínimo | macOS 14 |
| Permissões | Nenhuma (sem Acessibilidade) |

## 2. Estrutura

```
Package.swift                      // executableTarget "ClipPaste" + testTarget "ClipPasteTests"
Sources/ClipPaste/
  ClipItem.swift                   // modelo
  HistoryStore.swift               // lista, dedupe, limite 200, persistência
  ClipboardMonitor.swift           // polling do pasteboard
  HotKey.swift                     // atalho global Carbon, salvo em UserDefaults
  Panel.swift                      // NSPanel não-ativante + PanelView/CardView (SwiftUI) + drag
  ClipPasteApp.swift               // @main, NSApplication accessory, NSStatusItem menu, ligação
Tests/ClipPasteTests/
  HistoryStoreTests.swift          // dedupe, limite, round-trip JSON, classificação
Resources/Info.plist               // LSUIElement=true, bundle id com.ntz.ClipPaste
scripts/bundle.sh                  // release → build/ClipPaste.app + codesign ad-hoc
```

Fluxo: `ClipboardMonitor` detecta cópia → `HistoryStore.add` → ⇧⌘V (`HotKey`) → `Panel` mostra cards lendo o store → usuário arrasta card para um input → painel fecha.

## 3. Modelo

```swift
enum ClipKind: String, Codable { case text, image }

struct ClipItem: Codable, Identifiable, Hashable {
    let id: UUID
    var kind: ClipKind
    var createdAt: Date          // atualizado ao deduplicar
    var sourceBundleID: String?  // app de origem
    var text: String?            // .text
    var imageFile: String?       // "<uuid>.png" em blobs/ (.image)
    var imageWidth: Int?
    var imageHeight: Int?
    var hash: String             // SHA-256 do conteúdo (texto UTF-8 ou bytes PNG)
}
```

## 4. Componentes

### 4.1 HistoryStore
- `@Observable @MainActor final class`. `items: [ClipItem]`, mais recente primeiro.
- `init(directory: URL)` — injeta diretório (testes usam pasta temporária).
- `add(_:)`: se já existe item com mesmo `hash`, remove-o e reinsere no topo com `createdAt` novo (não duplica blob). Senão insere no topo.
- Limite `maxItems = 200`: remove excedentes do fim e apaga seus PNGs.
- `clear()`: esvazia lista e apaga `blobs/`.
- Salva `index.json` com `.atomic` após cada mudança (debounce 1 s é opcional; 200 itens de JSON é barato).
- Carrega no `init`; JSON corrompido → começa vazio (não crasha).

### 4.2 ClipboardMonitor
- `Timer` 0,5 s comparando `NSPasteboard.general.changeCount`.
- Ignora se `types` contém `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType` ou `org.nspasteboard.AutoGeneratedType`.
- Ignora se o pasteboard contém `.fileURL` (arquivos do Finder fora do MVP — e o Finder também coloca o ícone como TIFF, que não deve virar card).
- Prioridade: imagem (`.png` ou `.tiff` → converte para PNG via `NSBitmapImageRep`) antes de `.string`. Texto vazio/só espaços é ignorado.
- `sourceBundleID = NSWorkspace.shared.frontmostApplication?.bundleIdentifier`.
- Função pura testável para classificação: `static func classify(types: [NSPasteboard.PasteboardType]) -> ClipKind?`.

### 4.3 HotKey
- `RegisterEventHotKey` + `InstallEventHandler` (Carbon), sem permissão de Acessibilidade.
- Padrão `kVK_ANSI_V` + `cmdKey | shiftKey`. Persistido em `UserDefaults` (`hotKeyCode`, `hotKeyModifiers`).
- `update(keyCode:modifiers:)` desregistra o antigo e registra o novo; retorna `false` se o registro falhar.
- "Mudar atalho…" no menu: abre uma janelinha que captura o próximo `keyDown` com pelo menos um modificador (⌘/⌥/⌃), converte `NSEvent.ModifierFlags` → modificadores Carbon e chama `update`. Esc cancela. Falha → `NSAlert`.

### 4.4 Panel
- Subclasse de `NSPanel`: `styleMask [.borderless, .nonactivatingPanel]`, `level = .statusBar`, `collectionBehavior [.canJoinAllSpaces, .fullScreenAuxiliary]`, `isOpaque = false`, `backgroundColor = .clear`, `hasShadow = true`, `canBecomeKey = true` (necessário para receber Esc), `canBecomeMain = false`.
- Conteúdo: `NSHostingView` de `PanelView`, sobre `NSVisualEffectView` (`.hudWindow`, `.behindWindow`, cantos 16 pt).
- Posição: tela que contém o mouse (`NSEvent.mouseLocation`), `visibleFrame` com margem 8 pt, altura 300 pt, colado na borda inferior.
- Criado uma vez; `toggle()` faz `orderFrontRegardless()` + `makeKey()` / `orderOut(nil)`. Scroll volta ao início ao abrir.
- Fecha: Esc (`keyDown` keyCode 53 no panel), atalho de novo, clique fora (`NSEvent.addGlobalMonitorForEvents(.leftMouseDown)` enquanto visível), e após drop (ver 4.5).

### 4.5 PanelView / CardView (SwiftUI)
- Barra superior simples: ícone relógio + "Área de transferência" (chip), contador de itens. Estado vazio: "Copie algo para começar".
- `ScrollView(.horizontal)` + `LazyHStack(spacing: 16)`, cards 240×240, cantos 12.
- Cabeçalho do card (≈56 pt): azul para Texto, roxo para Imagem; título "Texto"/"Imagem" em negrito + tempo relativo pt-BR (`RelativeDateTimeFormatter`, `locale pt_BR`, `.full` → "há 7 minutos"); ícone do app de origem à direita (`NSWorkspace.shared.urlForApplication(withBundleIdentifier:)` → `icon(forFile:)`, 44 pt). Tempo atualiza via `TimelineView(.periodic(from: .now, by: 30))`.
- Corpo fundo escuro: texto até 8 linhas; imagem `aspectFit` sobre fundo xadrez. Miniaturas via `CGImageSourceCreateThumbnailAtIndex` (máx 480 px) com `NSCache`.
- Rodapé: detalhe (`"200 × 200"` ou `"123 caracteres"`) à esquerda, posição (1-based) à direita.
- **Drag** (`.onDrag`):
  - texto → `NSItemProvider(object: text as NSString)`
  - imagem → `NSItemProvider(contentsOf: blobURL)` (tipo `public.png`); se nil, registra `NSImage`.
- **Fechar após drop**: ao iniciar drag, instala `NSEvent.addGlobalMonitorForEvents(.leftMouseUp)` único; no mouse-up, se o cursor está fora do frame do painel, fecha o painel. Remove o monitor.

### 4.6 App
- `@main` com `NSApplicationDelegateAdaptor`; `NSApp.setActivationPolicy(.accessory)` (sem Dock, mesmo rodando via `swift run`).
- `NSStatusItem` com SF Symbol `doc.on.clipboard` e menu: "Abrir (⇧⌘V)" (mostra atalho atual), "Mudar atalho…", "Limpar histórico", separador, "Sair".
- UI em pt-BR.

## 5. Build

```bash
swift build          # debug
swift run            # roda sem bundle
swift test           # testes
./scripts/bundle.sh  # build/ClipPaste.app (arm64, ad-hoc)
```

`bundle.sh`: `swift build -c release`, cria `build/ClipPaste.app/Contents/{MacOS,Resources}`, copia binário e `Info.plist`, `codesign --force -s - build/ClipPaste.app`.

## 6. Testes

`swift test` com XCTest (Command Line Tools: se XCTest não estiver disponível, usar `import Testing`):
- dedupe move para o topo sem duplicar;
- limite 200 remove excedentes e seus blobs;
- round-trip `index.json` (salva, recarrega, igual);
- JSON corrompido → store vazio;
- `classify`: concealed → nil, fileURL → nil, png/tiff → image, string → text.

Manual (PRD §9): drag para Chrome, Slack, Notes; tela cheia; troca de atalho; reinício mantém histórico.

## 7. Pós-MVP

Busca, Enter/setas para colar (CGEvent + Acessibilidade), excluir item, links/arquivos como tipos, listas/pinboards, abrir no login.
